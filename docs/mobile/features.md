# 功能特性

## Live2D 模型渲染

*   **Cubism SDK**: 高性能渲染底座。
*   **触摸交互**: 支持点击模型不同区域触发不同反应。
*   **视角跟随**: 眼睛与头部跟随手指滑动。
*   **分区语音反馈**: 不同部位触摸可触发特定语音。

## AI 聊天

*   **OpenAI 兼容 API**: 广泛支持多种大语言模型。
*   **多轮对话**: 沉浸式连续交流体验。
*   **Markdown/LaTeX 渲染**: 富文本与公式完美显示。
*   **长按复制**: 便捷提取文字内容。
*   **聊天记录持久化**: 本地保存对话历史。

## 本地记忆

*   **自主判断**: 大模型自动判断是否需要写入记忆。
*   **记忆分类**: 支持事实、特质及短期记忆。
*   **自动摘要**: 长期记忆智能提炼，节省 Token。

## 本地语音合成

*   **端侧离线**: 彻底告别网络延迟与隐私泄露。
*   **模型获取**: 支持按需下载或本地 zip 文件导入。
*   **语速调节**: 满足个性化听感。

## 悬浮窗模式

*   **前台服务**: 保障进程稳定存活。
*   **交互手势**: 支持拖拽移动、捏合缩放。
*   **双击菜单**: 快速唤出快捷操作面板。
*   **快速三击**: 快速关闭悬浮窗。

## 多主题配色

*   **Material You**: 支持 Android 12+ 动态取色。
*   **主题模式**: 浅色、深色、跟随系统无缝切换。
*   **WCAG 对比度**: 保障文本在各种背景下的可读性。

## 隐私合规

*   **首次授权弹窗**: 明确告知权限用途。
*   **隐私政策**: 透明清晰的条款声明。
*   **日志导出**: 方便排查问题。
*   **数据授权管理**: 随时可撤销数据采集授权。
