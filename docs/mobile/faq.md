# 常见问题

## Q1: Live2D 模型不显示？

针对自行编译的情况：请检查是否已将 Live2D Cubism Core 的 `.aar` 文件正确放置在 `app/libs/` 目录下。

## Q2: API 连接失败？

1.  检查 API URL 格式是否正确（例如必须以 `http://` 或 `https://` 开头，并且包含完整的路径如 `/v1`）。
2.  确认 API Key 是否填写无误。
3.  检查手机网络连接，或是否需要代理环境。

## Q3: 语音模型下载失败？

1.  可能是网络波动导致，请重试。
2.  如果一直下载失败，可尝试在 Github 上下载模型 ZIP 包，通过"本地导入"功能加载。

## Q4: 悬浮窗不显示？

1.  请确保已在系统设置中授予本应用`"显示在其他应用上层"（悬浮窗）`权限。
2.  检查是否后台进程被系统强杀，尝试在任务管理中加锁。

## Q5: 记忆功能不工作？

1.  请在设置中检查`启用记忆`开关是否已打开。
2.  部分能力较弱的模型可能无法正确生成符合格式要求的记忆提取指令，建议使用能力强大的 LLM。
