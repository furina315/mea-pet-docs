# 配置指南

移动端设置页面采用二级导航结构，分为 5 个主要功能域。

## 提供商

### API 配置
| 设置项 | 说明 |
|--------|------|
| API Key | 你的 API 鉴权密钥 |
| API 地址 | OpenAI 兼容接口地址 |

### 模型参数
| 设置项 | 说明 |
|--------|------|
| 模型 | 要使用的 LLM 名称（如 gpt-4） |
| Temperature | 创意度调节 |
| 最大 Token | 单次回复最大长度限制 |

## 对话

*   **System Prompt**: 设定角色扮演的提示词。

### 记忆系统
| 设置项 | 说明 |
|--------|------|
| 启用记忆 | 是否开启本地记忆系统 |
| 自动摘要 | 是否在会话过长时自动进行摘要 |
| 摘要轮次 | 触发自动摘要的对话轮数阈值 |

## 外观

*   **背景壁纸**: 设置主界面的背景图片。
*   **聊天气泡透明度**: 调节气泡的透明度。
*   **主题**:
    *   模式：浅色 / 深色 / 跟随系统
    *   动态颜色：启用 Material You 取色
    *   颜色预设：多种主题色可选

## 语音 (TTS)

使用 local VITS 进行端侧语音合成。资源包格式支持 ZIP 导入。

### 语音模型状态卡
| 状态 | 说明 |
|------|------|
| 未下载 | 需点击下载或本地导入 |
| 已就绪 | 模型加载成功，可发声 |

### 发声选项
| 设置项 | 说明 |
|--------|------|
| 语速 | 调节说话的快慢 |
| 音量增强 | 调整语音输出音量 |
