# 移动端配置指南
移动端设置页面采用二级导航结构，分为4个主要功能域以及关于页面。

## 1. 提供商
可自定义多种提供商，填入 OpenAI 兼容的 API 基础 URL（含版本路径，如 `/v1`、`/v4`，不自动附加版本号）
### API 配置
| 设置项 | 说明 |
|--------|------|
| API Key | 你的 API 鉴权密钥 |
| API 地址 | OpenAI 兼容接口地址 |

### 模型参数
| 设置项 | 说明 |
|--------|------|
| 模型 | 要使用的 LLM 名称（如 deepseek-v41-flash） |
| Temperature | 随机度调节，区间为0~2.0 |
| 最大 Token | 单次回复最大长度限制，区间为256~8192 |

::: tip Temperature 参数作用
决定回复的随机程度。数值越低，模型越倾向挑高概率的词，回答更稳定、更贴合设定；越高则用词更多样、更有意外感，但也更容易偏题或前后矛盾。<br>
桌宠闲聊建议0.8~1.2；需要它严格听指令时降到 0.3 以下。<br>
注意：设为0也不保证每次输出完全一致；
部分提供商上限为1.0，推理模型会忽略此参数。
:::

## 2. 对话

*   **System Prompt**: 设定角色扮演的提示词，可自定义；底部卡片可恢复默认提示词。

### 记忆系统
| 设置项 | 说明 |
|--------|------|
| 启用记忆 | 是否开启本地记忆系统 |
| 自动摘要 | 是否在会话过长时自动进行摘要 |
| 摘要轮次 | 触发自动摘要的对话轮数阈值，区间为3-30 |

## 3. 外观

*   **背景壁纸**: 设置主界面的背景图片。
*   **聊天气泡透明度**: 调节气泡的透明度。
*   **主题**:
    *   模式：浅色 / 深色 / 跟随系统
    *   动态颜色：启用 Material You 取色
    *   颜色预设：12种主题色可选

## 4. 语音 (TTS)

使用 local VITS 进行端侧语音合成。资源包格式支持 ZIP 导入。

### 发声选项
| 设置项 | 说明 |
|--------|------|
| 语速 | 调节说话速度的快慢 |
| 音量增强 | 调整语音输出音量 |
