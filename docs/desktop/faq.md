# 常见问题

## 保存设置后，回复仍来自旧后端

请确保在修改 `config.json` 或环境变量后重启桌宠，或者在设置面板中点击了"应用并重启"。

## 有文本气泡，但没有语音

1. 检查 TTS 服务配置是否正确。
2. 确认网络连接正常（如果是云端 TTS）。
3. 检查系统音量设置。

## Hermes、OpenClaw、Agent Link 或远程 MCP 无法连接

1. 确保对方网关或服务已启动并在监听对应端口。
2. 检查配置中的 URL、Token 和证书（mTLS）是否正确无误。
3. 如果是本地连接，确保防火墙未拦截 `127.0.0.1`。

## Live2D 不渲染，或切换 PNG 后尺寸错误

请检查模型配置文件是否完整，特别是 `.model3.json` 中的尺寸和缩放设置。切换 PNG 时，确认贴图资源加载正常，没有跨域或路径错误。
