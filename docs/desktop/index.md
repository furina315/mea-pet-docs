# 桌面版项目介绍

MeaPet 是一款以 Windows 为主要平台、兼容 Linux 的 PyQt5 透明桌面宠物。它将角色立绘、AI 对话、语音合成、屏幕视觉、SQLite 记忆和好感度整合在一个桌面前端中，支持 Live2D 和 PNG 两种渲染方式。

## 当前功能

| 功能分类 | 具体功能 | 描述 |
| --- | --- | --- |
| 交互 | 聊天 | 支持接入大语言模型进行对话交互 |
| | 语音合成 | 接入 TTS 引擎实现语音回复 |
| | 视觉 | 支持屏幕捕获，实现视觉互动 |
| | Live2D | 支持 Live2D 动画互动 |
| 系统 | 记忆系统 | 记录用户聊天与互动，影响宠物好感度 |
| | 好感度系统 | 不同的好感度会有不同的对话表现 |
| 基础 | 快捷设置 | 提供直观的配置界面 |
| | 多渲染 | 兼容静态 PNG 图片渲染 |

## 设计理念

项目的核心设计理念是**清晰的职责边界**：将底层的数据处理、模型交互等逻辑与界面展示层分离，保持系统的高扩展性和稳定性。

## 技术栈

- **Python**: 3.10+
- **UI 框架**: PyQt5
- **数据库**: SQLite
- **动画渲染**: Live2D
